# Dreamer for Photoshop — Windows

Dreamer 是一款面向 Photoshop 的 AI 创作与修图插件。你可以用自然语言描述想法，和 AI 一起确认方向，再把结果带回可继续编辑的 Photoshop 图层。

当前发布版本仅适用于 **Windows x64**。

## 下载 / Download

- [下载最新 Dreamer for Windows x64 正式版](https://github.com/2771096196/psai/releases/latest)
- [Dreamer 官方网站](https://thoudreamer.com/)

## 系统要求 / Requirements

- Windows x64
- Adobe Photoshop 2025、Photoshop 2026 或更高版本
- Photoshop 最低内部版本：26.0
