# Dreamer for Photoshop

Dreamer 是一款面向 Photoshop 的 AI 创作与修图插件。你可以用自然语言描述想法，和 AI 一起确认方向，再把结果带回可继续编辑的 Photoshop 图层。

## 下载 / Download

- [下载最新 Windows x64 正式版](https://github.com/2771096196/psai/releases/latest)
- [Dreamer 官方网站](https://thoudreamer.com/)
- 支持 Photoshop 26.0 及以上版本
