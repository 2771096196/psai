Dreamer 是一款运行在 Photoshop 内的 AI 创作与修图插件。它不只是把一句 Prompt
交给生图模型，而是先读取当前 Photoshop 画面、选区和参考图，帮助你明确“要改什么、
必须保留什么、结果如何验收”，再把候选结果放回可继续编辑的图层、智能对象或蒙版。

适合摄影后期、Cosplay 创作、AI 插画、电商视觉、建筑表现，以及需要在生成式 AI 和
Photoshop 精修之间反复往返的创作者。

> [!IMPORTANT]
> **Dreamer 插件本体完全免费，登录可选；不需要购买 Dreamer 权益、激活码、设备绑定或 Token Plan 才能使用插件。**
> 没有 Token Plan，也可以配置独立的 GRS Key 直接生图；已有结果的对齐、光线贴回与本地
> 校色不需要聊天套餐。Chat 与 GRS 是独立第三方服务，实际模型调用费用由相应服务商收取。
> Dreamer 账号为后续 Skills 发放与社区同步预留，这些服务仍在建设中，当前不作为本地功能的使用前提。

## 1.4.0：从框选到贴回，再到光色融合

这一版把高频局部修改放到画布旁，把对齐和校色接到生成结果后面。移除路人、补齐背景、
修复画面、加入道具或调整氛围，都可以围绕同一个 Photoshop 选区继续完成。

- **选区旁浮条（Windows Beta）**：框选后就近输入需求，或选择填充、扩图、移除、修复、清理路人杂物的可编辑提示词。输入非空文字并提交后才读取 Photoshop 像素。
- **Fast 与 Agent 自由选择**：Fast 直接生成一张并自动贴回；勾选 Agent 则带着同一选区和参考图进入 AI 协作。Fast 默认 Nano Banana Pro / 4K，可改为当前可用模型支持的分辨率。
- **最多 5 张浮条参考图**：拖入或点选 JPEG、PNG、WebP，并给每张图写清用途；借造型、材质或氛围，PS 选区始终是修改与贴回的主锚点。
- **三种 Fast 对齐选择**：Dreamer、PS 原生或关闭内容对齐。结果可再次贴回并尝试另一种对齐方式，复用已生成图片，不再发起生图请求。
- **生成历史接续工作**：只读最终卡保留实际 Prompt、图片和参数；生成与贴回分别显示进度。收起浮条或换选区后，已提交任务继续处理原选区，历史记录可回看并再次贴回。
- **自动校色 / 手动微调（Beta）**：从结果卡直接展开，也可从快捷入口进入。框选原图与结果中未改变的同一块区域，创建剪贴曲线，再调强度、RGB 和亮度，让新结果更自然地融入原片。
- **更好整理 PSD**：新结果名称标明极简、简洁、Agent 或快速描述来源，以及贴回方式和候选；快捷入口与极简任务窗可分别拖动、收起和恢复位置。

> 新增浮条、PS 原生对齐与自动校色目前已有源码、模拟接口及隔离界面验证，仍以 **Beta** 提供。
> Photoshop 真机中的定位、中文输入、蒙版边缘、对齐精度、校色观感与撤销需要实际使用验收；
> 自动检查通过不代表上述真机项目已通过。模型可用性、积分与分辨率以插件实时目录为准。

## 为什么在 Photoshop 里使用 Dreamer

- **直接理解当前画面**：有选区时读取选区，无选区时读取整图；当前文档同时成为生成输入和贴回锚点。
- **先确认，再生成**：复杂任务会把目标、保护项、参考图职责、最终 Prompt 和生成参数放到 Review 中确认，减少误生成和误计费。
- **按任务选择速度**：画布旁浮条处理局部快修；极速模式管理预设与参数；复杂合成、扩图和多轮判断交给 Dreamer AI 搭档。
- **结果仍留在 Photoshop**：原图保留，每次选择一个候选贴回一个结果层或任务组，可继续用蒙版、混合模式和调整层精修。
- **能力可以沉淀**：提示词预设、Skills、素材库、会话和生成资产都能持续复用，不必每次从空白 Prompt 开始。
- **过程可追溯**：生成资产记录保留输入、Prompt、模型、尺寸、耗时、候选与贴回状态；结果层误删时可以从已有记录再次贴回，无需重新生成。

## 两种主模式，加一个画布旁入口

| 模式 | 适合场景 | 工作方式 | 需要配置 |
| --- | --- | --- | --- |
| **极速模式 · 直接生成** | 目标明确、已有 Prompt、常用预设、局部快速修改 | 选择预设或编辑 Prompt，确认主图、参考图和参数后直接生成；不经过多轮 Agent | 独立 GRS Key；无需 Chat / Token Plan |
| **极速模式 · 看图升级 Prompt** | 有明确方向，但希望 AI 补全构图、保护项和质量要求 | Chat 只分析当前画面并升级文字，不会自动提交付费生成 | 可用的 Chat 服务；真正生成时再需要 GRS Key |
| **Dreamer AI 搭档** | 扩图、复杂合成、多参考图、目标不完整或需要多轮判断 | Agent 理解画面、按需澄清、选择 Skills、组织参考图职责，发布最终 Review 后再生成 | 可用的 Chat 服务；真正生成时需要 GRS Key |
| **框选浮条 · Fast（Beta）** | 在画布上连续处理多个局部修改 | 非空需求提交后直接生成一张并自动贴回；只读最终卡保存当次输入，不需要再次点击确认 | 独立 GRS Key；无需 Chat / Token Plan |
| **框选浮条 · Agent（Beta）** | 选区明确，但希望 AI 帮忙组织修图方案 | 显式勾选可用的 Agent 后，把选区、辅助图和逐图说明带入独立会话；生成参数在最终 Review 中确认 | 当前入口就绪的 Chat 服务；真正生成时需要 GRS Key |

两种主模式与浮条复用 Photoshop 读取、任务记录和贴回能力。Fast 的提交就是本次生成与
自动贴回的确认；关闭浮条只影响显示，已经提交的任务会继续。页面重载后只恢复历史状态，
不会因为恢复记录再生成或自动补贴。

## Token Plan 用在哪里？没有套餐能做什么？

**Token Plan / Coding Plan 是聊天服务的计费方式，不是 Dreamer 的解锁凭证，也不是 GRS
生图积分。** 配置聊天服务后，Dreamer 可以看图理解、整理 Prompt、沟通方案和执行 Agent
工作流；所选模型是否支持看图、套餐额度和接口权限，仍以该服务与插件设置显示为准。

| 已接入的 Chat 服务 | 当前配置方式 |

| **MiniMax** | API 按量计费 / Token Plan |
| **小米 MiMo** | API 按量计费 / Token Plan |
| **Kimi** | 开放平台 API / Coding Plan，使用各自对应的 Key 与模型 |

没有 Token Plan 时，可以先用 **极速直生 / 浮条 Fast + GRS Key** 完成生图，再用本地工具
检查对齐、进行光线贴回和自动校色。复用已保存候选进行贴回、对齐或调色，不重新请求
生图；如果另行生成新图片，仍按 GRS 当前规则消耗积分。需要 AI 对话与规划时，再按需
配置可用的 Chat API、套餐或自定义服务。

账号注册和登录为可选项。后续计划通过账号提供 Skills 发放与社区同步，**目前建设中**；
现有的本地 Skills、预设、会话和素材管理可以继续在本机使用。

## 通用创作能力

- **光线调整**：保持原布光进行补光、压光、暗部和光比修正；重新设计有来源的动机光、氛围光与冷暖关系；根据画笔、箭头、选区或颜色标记重建光路。
- **视角调整**：按真实相机逻辑处理轻微俯仰、升降、环绕、远近、焦段感和取景变化，同时约束身份、结构、遮挡、视差与透视。
- **画面修复**：移除指定文字、水印、字幕和覆盖物；新增、压制或移除物理可信的镜头光晕、Ghost、Starburst、Bloom 等光学效果。
- **道具与透明素材**：道具库支持生成、上传和整理素材；可按入口使用 Photoshop 选择主体生成透明素材，再放入 PS 或加入参考图。已有透明素材可以保留其透明背景。
- **海报与视觉包装**：活动 KV、摄影海报、角色 IP、社媒封面、电商视觉、多图拼贴、网格排版、标题层级和可编辑文字协作。
- **素材与提示词沉淀**：管理参考图、道具素材、生成资产、提示词 Wiki 与个人 Skills；可从成功案例和反馈中提炼下一次可复用的经验。
- **选区快修（Beta）**：把“移除这个路人”“补齐右侧墙面”“修复这段衣料”写在画布旁；快捷提示词可继续修改，参考图可逐张注明只借用的部分。
- **自动校色（Beta）**：在原图与结果的相同位置框选未改变区域，用它作为颜色标尺，再把校正作用于整个目标或仅当前选区；输出可继续微调的 Photoshop 调整层，不消耗图像生成积分。

## 结果如何贴回 Photoshop

贴回方式会根据当前任务、已验证的 Skill、选区和生成输入自动开放；不是所有任务都会
同时显示全部按钮。

### 保真整图

把完整候选作为一个智能对象放回冻结的 Photoshop 文档，保留生成结果的颜色、构图和
像素外观。适合换景、整体重绘、风格化和需要把候选当作完整成片继续精修的任务。

### 选区与任务组蒙版

局部任务会沿生成前冻结的选区定位，建立新的任务组和组蒙版。原图保持不动，用户可以
用黑白画笔控制结果显隐、修接缝、切换候选或删除整个任务组。一次贴回只落一个候选和
一个结果层，不会把扁平成图伪装成已经自动拆好的语义 PSD。

### 保真光线贴回

光线任务可以不把整张生成图覆盖回来，而是比较生成结果与冻结原图，提取**新增的正向
光能**，创建标明来源与“光线贴回”的任务组和一张新增光效黑底智能对象，并使用
Photoshop **线性减淡（添加）** 混合模式叠加到原图上。

可调项目包括：

- **光线强度**：保留原始生成效果，或在贴回前降低/增强新增光线；
- **脏边清理**：减少人物、树叶和物体边缘附近的彩色碎边；
- **高光保护**：压低接近纯白的过亮区域；
- **光线清晰度**：在发丝、轮廓、材质细光与更柔和的光线之间调整；
- **自动对齐**：在允许的范围内校正生成结果与冻结原图的位置偏差。

这一方式适合补光、轮廓光、氛围光和局部光效。它的目标是保留原图细节，把新增光线
单独留成可开关、可改混合模式、可继续蒙版精修的图层；生成图变化过大或无法可靠对齐时，
应改用保真整图，而不是强行声称“只贴回了光”。

### 分类特效贴回

特效模式按照用户选择的类别处理结果：光、雾烟、火焰、雷电和粒子会形成黑底线性减淡
效果层；花瓣、柳叶等实物保留原色纹理与软蒙版；灵体、护盾等半透明对象会把本体和灵光/
环境响应分开。这样可以在 Photoshop 里分别调整能量、密度、颜色、遮挡和显隐。

### 抠图的当前范围

道具库的 Photoshop 选择主体、透明素材导入，与“让 AI 生成 Alpha 蒙版后再贴回”是不同
流程。**1.4.0 客户包暂未提供“物体提取与抠图”专属 Skill**，因此本页不将后者列作开箱即用
能力。处理主体边缘仍可使用 Photoshop 原生选择主体、选择并遮住和图层蒙版。

### 分向扩图贴回

扩图会先明确上、下、左、右方向以及目标尺寸，再真实扩展 Photoshop 画布。每个方向使用
独立参考窗口和带重叠羽化的蒙版贴回，尽量让天空、墙面、地面和植物等连续纹理自然越过
原画布边界，同时保留原图像素和可逆的边缘控制。

浮条中的“扩图”快捷项是另一种轻量用法：先由你在 Photoshop 准备画布与选区，露出待
补齐的黑色或白色空白，再提交补全需求。快捷项本身不扩大画布，也不会替你调整选区。

### 对齐与光色融合

Fast 对齐提供 **Dreamer / PS 原生 / 关闭** 三种选择。前两者以生成时保存的主图为依据，
关闭时仍按原文档、原选区位置和蒙版贴回，只是不做内容校正。对齐不可靠时应检查回执和
轮廓，不能把“图片已经贴回”当作“对齐成功”。再次贴回会创建新的可编辑副本。

在结果卡展开 **自动校色 / 手动微调**，核对原始参考层与目标层，再框选两者相同位置、
内容未明显改变的区域作为颜色标尺。默认作用于整个目标，也可仅作用于当前选区。
Dreamer 会创建剪贴 RGB 曲线调整层；自动强度可调 **0–200%**，红、绿、蓝和亮度分别可调
**−20 至 +20**。拖动持续修改同一校色层；“恢复默认”回到本次自动结果，只有重新取样才
创建新的校色层。支持 RGB 8/16 位文档；32 位 HDR 或非 RGB 文档请准备 RGB 8/16 位副本。

校色以像素对应为前提。先检查对齐，再选没有被改动的背景或纹理区域；被移除的人物、
重画的衣服或完全替换的天空不适合作为“原本应相同”的颜色标尺。原始像素保持可继续编辑。

## 一次完整工作流

1. 在 Photoshop 打开副本，选择要修改的局部；没有选区时 Dreamer 使用整张文档。
2. 选择极速模式或 AI 搭档，说明目标，并按需添加参考图及各自用途；常规输入区上限以界面为准，Windows 浮条支持最多 5 张辅助图。
3. 生成前检查实际发送图片、Prompt、模型、尺寸、候选数和保护项。
4. 查看真实候选，选择一张贴回；Dreamer 建立新图层、智能对象或任务组，不覆盖原图。
5. 回到 Photoshop 检查蒙版与对齐，再从结果卡使用自动校色 / 手动微调，或用曲线、色彩平衡和混合模式完成最后的人工判断。

对于复杂作品，推荐把后景、道具、光效、粒子等拆成多轮单目标任务。每一轮只解决一个
清晰问题，通常比一次要求模型同时完成所有内容更稳定，也更容易在 PSD 中独立修改和回退。

## 安装与首次使用

Windows 1.4.0 的目标运行环境：

- Windows x64；
- Adobe Photoshop 2025、Photoshop 2026 或更高版本；
- Photoshop 内部版本 26.0 或更高。

安装步骤：

1. 从 [GitHub Releases](https://github.com/2771096196/psai/releases/latest) 或[官方网站](https://thoudreamer.com/#download)下载最新 Windows ZIP。
2. 解压后，把单个 `Dreamer` 文件夹放入 Photoshop 的 `Plug-ins` 目录。
3. 完全退出并重新打开 Photoshop。
4. 打开 Dreamer 即可进入免费插件；账号登录可选，无需激活码和设备绑定。
5. 直接生图只需配置 GRS Key；需要看图升级或 AI 搭档时，再配置 Chat 服务。先用照片副本完成一次 1K、单候选测试。

macOS 与 Windows 共用同一套客户端业务源码，但 macOS 正式包必须在真实 Mac 上完成原生
编译、Developer ID 签名、公证、Gatekeeper 与 Photoshop 验收；在这些门禁完成前，本页
不提供未经验证的 macOS 正式下载。

## 隐私、凭据与能力边界

- Dreamer 会把会话、参考图、生成结果、设置、日志、Skills 状态和账号会话保存在本机 `Dreamer/user-data`。
- Chat Key 与 GRS Key 分开配置，只用于调用相应服务；不要把 Token、API Key、AK、密码或客户原图发到公开 Issue、群聊、截图和诊断日志中。
- 生成模型具有随机性，人物身份、手指、文字、精确结构和像素级局部控制仍可能出错。重要项目请保留原图、使用小选区、单目标多轮和 Photoshop 蒙版复检。
- “保护人物”“只改光线”等是工作流约束和验收目标，不是对第三方生成模型的绝对保证。
